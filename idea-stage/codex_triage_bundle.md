# 跨模型分级任务包（ARIS /idea-creator Phase 4 · devil's advocate triage）

你是 CoRL / RSS 资深审稿人，与生成这些想法的模型不是同一个「人」。请完整阅读：

1. `idea-stage/IDEA_CANDIDATES.md` —— 去重、过可行性门后的 21 条候选（C01–C21），含 prior_work / so_what / effort_note 标注
2. `idea-stage/codex_brainstorm_astra.md` 与 `idea-stage/codex_brainstorm_second.md` —— 每条想法的完整字段（pilot 设计、指标、失败模式、风险）
3. `idea-stage/ROBOTICS_FRAME_AND_LANDSCAPE.md` —— 问题框架、资产与预算

## 任务

对**每一条**候选：
- 最强的支持理由：什么结果会让它成为被引用的那篇？
- 审稿人最强的反对意见
- 最可能的失败模式
- prior_work 标注是真正的新颖性问题，还是可以区分的？
- 在 pilot 预算（≤ 8×80GB × 1 周、仿真优先、无真机）内的**期望信息量与上行空间**

然后**给出排名**（只排名，不重写想法）。规则：
- 反对意见要么被回答、要么作为「命名风险」记录在该想法上——**不得**通过加模块、加门控、加限定词来吸收。
- 一个大胆想法 + 一条命名风险，优于一个无风险的保守想法；比 brainstorm 阶段更复杂的版本是红旗而不是进步。
- 不要让前几名全是低风险项：如果前三名全为 LOW 风险，请单独指出最值得占一个 pilot 名额的高上行想法，以及什么结果会说服你。
- 考虑「簇」：同簇想法若同时入选，说明为何两条都值得做，否则只选簇内最强的一条。
- 你的排名分配的是稀缺的 pilot 名额，不是淘汰判决：未入选的可行想法仍是候选。

## 输出格式（简体中文）

```
## 逐条评审
### C01 <标题>
- 支持：
- 反对：
- 失败模式：
- 新颖性：可区分 / 有真实问题（说明）
- 风险等级：LOW / MEDIUM / HIGH
- 期望信息量：高 / 中 / 低（一句话）
（C02 … C21 同上）

## 排名（1 = 最值得占 pilot 名额）
1. Cxx — 一句话理由
2. …
（列全 21 条）

## 我会真正去做的 2–3 条，以及为什么

## 高上行想法（若前三名全为 LOW 风险）
- Cxx — 什么结果会说服我
```
不要输出其他内容。
